Connect your cloud database

To sync bills between your laptop and phone, connect a Supabase project first. Your database credentials are saved in this browser only. Use the project's public anon/publishable key—not a service-role secret.

One-time setup:
  1. Create a free project at supabase.com.
  2. Open SQL Editor and run the included schema.sql file.
  3. Open Project Settings → API (or Connect) and copy the Project URL and publishable/anon key.
  4. Paste them above, connect, then create an account below.
  5. Open this app on your other device and enter the same URL/key and sign in with the same account.
